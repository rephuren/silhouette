# История изменений

## Не выпущено

### Добавлено
- `--fail-on` и `--fail-on-new` у `scan` и `report`: код возврата 3, если порог серьёзности превышен (#7)

## 0.2.0

### Добавлено
- проект переименован из `umbra` в `silhouette`
- пакет и команда `silhouette`, CI на Python 3.10, 3.12 и 3.14, `ruff`, `mypy`
- кэш ответов crt.sh (`--cache-ttl`, `--no-cache`), пауза между запросами, поддержка `Retry-After`, нарастающая пауза с случайной добавкой
- ограничение скорости активных проб `--rps`

### Исправлено
- клиент DNS больше не падает в системе без `resolv.conf`: берёт публичные резолверы
- разбор ответа crt.sh отвергает неверную форму JSON и пропускает посторонние записи
- путь кэша не может выйти за пределы папки кэша
